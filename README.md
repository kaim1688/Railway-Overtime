# 三班制加班時數計算器

匯入 Excel，查看各員工加班時數與每日明細，並匯出核對報表。只計時數，不計金額。

## 使用與資料處理
- 匯入 .xlsx、選月份和上方三班制區段，核對國定本日清單後計算。
- Excel 在自己的瀏覽器記憶體中解析，程式不將班表上傳到 GitHub 或其他服務。
- 重新整理清除班表；localStorage 只保存淺色／暗色偏好。
- 公開程式只有合成的「範例員工」，不含真實員工班表、報表或截圖。
- 網站與程式碼公開；主機服務仍可能記錄一般造訪資訊，例如 IP、時間與請求路徑。
- 未知班別、跨月資料不足、重複轉移須人工核對；結果供內部試算，非正式核定規章。
- 只有2026年10月預填國定日期；其他月份需自行確認，不能直接套用補假日。
