# 台鐵班表加班時數計算器

匯入 Excel，查看各員工加班時數與每日明細，並匯出核對報表。只計時數，不計金額。

## 使用與資料處理
- 匯入 .xlsx 後自動辨識月份，計算上方三班制及下方常日班替班人員；只在資料有問題時提醒。
- 下方前三位站長及兩位總務、段替班依既有班表排列排除；排列變更時需先整理版型。
- 支援常日班國定日 8 小時班未標星號、同月之後明確補休該日的對應核對。
- 延時工資分列 0–2H、3–4H：常日平日替班每班 2H／1H，三班制普通日／夜每班 1.2H／0H；總表、明細與匯出一致，只計時數。
- 2026/10/23、10/24 依已知班別另計颱風出勤，取消原延時及一般時數；網頁末表與 Excel 最後工作表獨立統計，不併入國定或一般總計。
- 支援列印全體統計表（A4 橫向）及所選員工逐日明細，包含各類時數合計。
- 「加班時數計算規則」預設收合，可點開查看 0H 假別與例外說明。
- 2026/11/28 依使用者確認：三班制星號日／夜班、常日星號替日班計國定出勤 8／2／1H；常日已知 8 小時星號班計 8H。不另加普通延時，也不自動套用一般國定例休或公休轉移。
- Excel 在自己的瀏覽器記憶體中解析，程式不將班表上傳到 GitHub 或其他服務。
- 重新整理清除班表；localStorage 只保存淺色／暗色、文字大小及動畫偏好。
- 公開程式只有合成的「範例員工」，不含真實員工班表、報表或截圖。
- 網站與程式碼公開；主機服務仍可能記錄一般造訪資訊，例如 IP、時間與請求路徑。
- 未知班別、跨月資料不足、重複轉移須人工核對；結果供內部試算，非正式核定規章。
- 已內建 2026 年 10–12 月及 2027 全年的實際國定本日，不包含政府補假日；其他月份需自行設定。
- 日期來源：全國法規資料庫 https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0020095 及人事行政總處 2026、2027 行事曆。只取實際國定本日，核對日為 2026-10-19。
